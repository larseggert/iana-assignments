 identify the command.

6P Return Codes

Registration Procedure(s)

             IETF Review or IESG Approval


Reference
        [RFC 8480]

Note

 In the 6top Protocol (6P) version 0 [RFC 8480], there
 is a Code field which is 8 bits in size.  In a 6P
 Response or 6P Confirmation, the value of this Code
 field is used to identify the return code.


Available Formats
        [IMG]
        CSV

 Code       Name            Description       Is Error? Reference
0      RC_SUCCESS      operation succeeded    No        [RFC 8480]
1      RC_EOL          end of list            No        [RFC 8480]
2      RC_ERR          generic error          Yes       [RFC 8480]
3      RC_RESET        critical error, reset  Yes       [RFC 8480]
4      RC_ERR_VERSION  unsupported 6P version Yes       [RFC 8480]
5      RC_ERR_SFID     unsupported SFID       Yes       [RFC 8480]
6      RC_ERR_SEQNUM   schedule inconsistency Yes       [RFC 8480]
7      RC_ERR_CELLLIST cellList error         Yes       [RFC 8480]
8      RC_ERR_BUSY     busy                   Yes       [RFC 8480]
9      RC_ERR_LOCKED   cells are locked       Yes       [RFC 8480]
10-255 Unassigned
