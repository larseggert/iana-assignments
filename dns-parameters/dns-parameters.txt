DNS CLASSes

Expert(s)

             Petr Špaček, Ladislav Lhotka


Reference
        [RFC 6895][RFC 9108]

Note

 As noted in [RFC 6762], Multicast DNS can only carry DNS records with classes in the range 0-32767.
 Classes in the range 32768 to 65535 are incompatible with Multicast DNS.

Note

 When this registry is modified, the YANG module [iana-dns-class-rr-type]
 must be updated as defined in [RFC 9108].
